第一階段：基本運算與輸入輸出 (1-5)

	1.	兩數之和：讓使用者輸入兩個數字，計算並輸出它們的和。
	2.	圓面積計算：輸入半徑，計算圓面積（‭‬ 取 3.14159）。
	3.	溫標轉換：將攝氏溫度轉換為華氏溫度。公式：‭‬‭‬‭‬‭‬。
	4.	變數交換：不使用第三個變數，交換兩個變數的值。
	5.	BMI 計算器：輸入身高（公分）與體重（公斤），計算並輸出 BMI 值。
  
第二階段：條件判斷 (6-10)

	1.	奇偶數判斷：輸入一個整數，判斷它是奇數還是偶數。
	2.	閏年判斷：輸入年份，判斷是否為閏年（能被 4 整除但不能被 100 整除，或能被 400 整除）。
	3.	三數取最大值：輸入三個數字，找出並輸出其中的最大值。
	4.	成績評等：輸入分數，輸出對應等級（90+ 為 A，80-89 為 B...以此類推）。
	5.	正負數判斷：判斷輸入的數字是正數、負數還是零。
  
第三階段：迴圈練習 (11-15)

	1.	累加求和：計算 1 到 100 的所有整數總和。
	2.	九九乘法表：使用巢狀迴圈印出整齊的九九乘法表。
	3.	階乘計算：輸入 ‭‬，計算 ‭‬‭‬（例如 ‭‬‭‬‭‬‭‬‭‬‭‬‭‬）。
	4.	費氏數列 (Fibonacci)：輸出費氏數列的前 ‭‬ 個數字（1, 1, 2, 3, 5, 8...）。
	5.	水仙花數 (Narcissistic number)：找出所有三位數的水仙花數（每個位數的立方和等於該數本身，如 ‭‬‭‬‭‬‭‬）。
  
第四階段：數值邏輯與進階迴圈 (16-20)

	1.	質數判斷：輸入一個整數，判斷它是否為質數。
	2.	找出範圍內質數：找出 1 到 100 之間所有的質數。
	3.	整數反轉：將輸入的整數反過來輸出（如輸入 1234，輸出 4321）。
	4.	位數總和：計算一個整數中各個位數數字的和（如 123 = 1+2+3 = 6）。
	5.	最大公因數 (GCD)：輸入兩個數字，找出它們的最大公因數。
  
第五階段：字串與串列操作 (21-25)

	1.	字串反轉：將輸入的字串反過來（如 "Python" 變成 "nohtyP"）。
	2.	迴文判斷 (Palindrome)：判斷字串正著讀跟倒著讀是否一樣（如 "radar"）。
	3.	統計元音：計算字串中英文字母元音（a, e, i, o, u）的個數。
	4.	串列最大與最小：在一個數字串列中，找出最大值與最小值。
	5.	移除重複項：給定一個串列，移除其中重複的元素。
  
第六階段：綜合邏輯 (26-30)

	1.	完美數判斷：判斷一個數是否為完美數（除本身外所有因數之和等於該數，如 6 = 1+2+3）。
	2.	星號三角形：根據輸入的層數 ‭‬，印出直角三角形或等腰三角形。
	3.	清單排序：手寫一個簡單的排序（如冒泡排序），將串列由小到大排列。
	4.	猜數字遊戲邏輯：隨機產生一個 1-100 的數字，讓使用者猜，並提示「太大了」或「太小了」。
	5.	楊輝三角 (Pascal's Triangle)：輸出前 ‭‬ 行的楊輝三角。
